# Merajut Walasuji — Edisi Malam Elegan

Game edukasi transformasi geometri berbasis etnomatematika Bugis.

## Menjalankan
1. Ekstrak ZIP.
2. Buka folder `Merajut_Walasuji_Elegan` di VS Code.
3. Jalankan `index.html` menggunakan Live Server atau buka langsung di browser.

## Pembaruan tampilan dan permainan
- Latar hitam elegan dengan aksen emas dan pola geometris.
- Animasi masuk halaman, efek mengambang pada motif, kilau emas, serta transisi tombol dan kartu.
- Tata letak responsif untuk ponsel dan desktop.
- Tombol navigasi, pilihan jawaban, petunjuk, coba lagi, refleksi, rumus, dan lembar catatan tetap interaktif.
- 12 level dalam tiga tahap: Pemula, Menengah, dan Lanjutan.
- Tiap level memiliki tiga soal, petunjuk bertahap, umpan balik, dan refleksi.
- Efek bunyi benar/salah dapat diaktifkan dari tombol nada di bagian atas.
- Progres tersimpan di browser menggunakan localStorage.

## Catatan konten
Dua belas level dibangun dari empat konsep dan bank soal yang sudah ada pada aplikasi sumber, lalu disusun menjadi tiga tahap. Karena itu, beberapa soal inti berulang antartahap. Jika ingin setiap level memiliki soal yang benar-benar berbeda, bank soal tambahan perlu disusun dan ditinjau kebenaran matematisnya.

Aplikasi ini berupa web app (HTML, CSS, JavaScript), bukan APK Android. Prototipe belum divalidasi dan perlu diuji pada perangkat sasaran.
