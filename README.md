# Merajut Walasuji — Paket Bersih

Aplikasi game edukasi transformasi geometri berbasis etnomatematika Bugis.

## Identitas dan aset
- Paket ini hanya memuat identitas **Merajut Walasuji**.
- Seluruh aset gambar dari proyek/brand **Anyaman Semesta** tidak disertakan.
- Tidak ada file gambar (PNG, JPG, JPEG, WEBP, GIF, atau SVG) di dalam paket ini.
- Ornamen geometris yang tampil dibuat langsung menggunakan CSS/HTML, bukan mengambil gambar dari proyek Anyaman Semesta.

## Menjalankan aplikasi
1. Ekstrak ZIP.
2. Buka folder `Merajut_Walasuji` di VS Code.
3. Jalankan `index.html` menggunakan Live Server atau buka langsung di browser.

## Isi paket
- `index.html` — kerangka halaman aplikasi.
- `style.css` — tampilan hitam elegan, aksen emas, animasi, dan bidang koordinat.
- `script.js` — navigasi dan interaksi permainan.
- `manifest.webmanifest` — metadata aplikasi web.

Paket ini merupakan aplikasi web, bukan APK Android.
